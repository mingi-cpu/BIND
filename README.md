# Clone Coding Homework

This repository contains clone coding and small web practice projects created for educational and homework purposes.

The projects are not affiliated with, endorsed by, or sponsored by the original services or companies referenced below. No commercial use is intended.

## Project Overview

| Path | Project | Notes |
| --- | --- | --- |
| `01_copyNetflix/` | Netflix clone coding | Recreates a Netflix-style page layout for study. |
| `02_copyApple/` | Apple Store clone coding | Recreates an Apple Store-style page layout for study. |
| `03_toDoList/` | To-do list practice | Basic HTML/CSS/JavaScript practice project. |
| `04_quizGame/` | Quiz game practice | Basic quiz UI and JavaScript logic practice project. |
| `05_movie/` | Movie API practice | Fetches sample movie data from an external API. |
| `06_api/` | API fetch practice | Fetches sample data from an external mock API. |
